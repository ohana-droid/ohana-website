# ヘルパーステーションohana ホームページ

合同会社ロカヒが運営する「ヘルパーステーションohana」(千葉市稲毛区)のホームページです。
HTMLとCSSだけで作った静的サイトで、GitHub Pages などの無料ホスティングで公開します。

## ページ

| ファイル | ページ |
| --- | --- |
| `index.html` | ホーム |
| `office.html` | 事業所情報 |
| `service.html` | サービス内容 |
| `recruit.html` | 採用情報 |
| `company.html` | 会社概要 |

共通のデザインは `assets/css/style.css`、画像は `assets/img/` にあります。
スマホ用メニューの開閉だけ `assets/js/main.js` を使っています。

## 画像について

- `assets/img/hero.jpg`: トップの海の写真(Unsplash の無料写真 photo-1592880477040-7e90149b258c。Unsplash License で商用利用可、クレジット表記は任意)。代表者撮影の写真に差し替え予定です。
- `assets/img/logo.png` ほか: ohana のロゴ。
